## Upgrading from 0.13: update through 0.13.21

**A device running 0.13 can move to 0.14 over the air, through 0.13.21.**
Releases up to 0.13.20 cannot read 0.14's OTA v3 format, so they reject a 0.14
package and report `downloaded_package_invalid`. 0.13.21 is a bridge release
that accepts it.

1. Install the 0.13.21 bridge release by hand. It is a separate release, not
   the latest one, so 0.13 devices do not find it on their own. Download
   `libreecho-radar-puffin-v0.13.21.ota.tar` from the
   [0.13.21 release](https://github.com/aslater3/LibreEcho/releases/tag/radar-puffin-v0.13.21),
   then use **System** > **System update** > **Select update file** and
   restart. The file is for the stable channel; switch **Update channel** to
   **stable** first if the device is on dev.
2. Optionally, repair the bootloader and install TWRP from the **Bootloader**
   panel, if 0.13.21 offers it. This is only for units installed with 0.13's
   BROM method, and it is not needed for 0.14.
3. Select **Check for updates**. 0.13.21 offers 0.14. Install it and restart.

0.14 carries over 0.13's versioned configuration, so the update is intended to
keep settings, Wi-Fi and the account. Download a configuration backup first.
Hardware validation: TODO — validated on hardware: <pending>.

If a 0.13 device still reports `downloaded_package_invalid`, it has not
reached 0.13.21 yet. Install 0.13.21 from its file first (step 1), then update
to 0.14.

Reinstalling with the installer in the
[installation guide](https://github.com/aslater3/LibreEcho/blob/main/docs/install/README.md)
remains the fallback. It formats userdata, so settings, Wi-Fi credentials,
accounts and pairings are not kept, and setup runs again after the first boot.

Full steps, including the optional bootloader repair and a fix for 0.13 units
stuck in fastboot after an earlier 0.14 install attempt, are in the
[0.13.21 upgrade guide](https://github.com/aslater3/LibreEcho/blob/radar-puffin-v0.13.21/docs/install/README.md#upgrading-from-013-to-014)
and the
[0.13.21 release notes](https://github.com/aslater3/LibreEcho/blob/radar-puffin-v0.13.21/release/radar-puffin-v0.13.21.md).
